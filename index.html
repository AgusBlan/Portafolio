Grab Puppeteer — Project Overview

Juego de control de marionetas. El jugador controla hilos, danza y ritmo para exorcizar fantasmas. Género: ritmo + acción. Emoción: teatral, misterioso, divertido.

PROJECT OVERVIEW

Juego de ritmo y control. El jugador mueve marionetas con los dedos, combina danza y música para avanzar.

SCENARIO OVERVIEW

Niveles por escenarios: teatro, calle, templo. Cada nivel desbloquea un baile y un fantasma nuevo.

WORLDVIEW SETTING

Mundo de teatro japonés, rituales, fantasmas y música. Paleta roja, dorada y oscura.

KEYWORD EXTRACTION

Ritual — Danza — Teatro — Música — Fantasma — Exorcismo
